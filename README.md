# Port Scanner

A simple TCP port scanner written in Python.

## Usage

python portscan.py

When prompted, enter:
- Target IP address or hostname
- Starting port
- Ending port

## Example

Target: 192.168.1.1  
Starting port: 20  
Ending port: 100  

Open ports:  
22  
80
