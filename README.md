# Port Scanner

A simple TCP port scanner written in Python.

## Usage

```text
python portscan.py
```

When prompted, enter:

* Target IP address or hostname

## Example

```text
Enter target IP or host: 192.168.1.1

--------------------------------------------------
Scanning target: 192.168.1.1
Scanning started at:2026-08-11 13:45:00.123456
--------------------------------------------------
Open ports:  
22  
80  
Scan complete
```
